# Théorie des graphes dans le web

Le web, les réseaux sociaux, les recommandations… tout est un **graphe**.

Un graphe \( G = (V, E) \) : sommets (nodes) + arêtes (edges).

graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E']
}

def bfs(start, goal):
    queue = deque([(start, [start])])
    visited = {start}
    while queue:
        node, path = queue.popleft()
        if node == goal:
            return path
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))
    return None

print("Chemin A → F :", bfs('A', 'F'))`}
