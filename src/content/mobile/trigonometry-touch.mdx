# Trigonométrie pour les interactions tactiles

Après la physique de chute libre, l'autre pilier des interfaces mobiles fluides : la **trigonométrie**, pour interpréter les gestes tactiles.

## Calculer l'angle d'un swipe

Quand un doigt glisse d'un point A à un point B, on veut souvent savoir dans quelle direction :

<Math display>{`\\theta = \\text{atan2}(\\Delta y, \\Delta x)`}</Math>

`atan2` (contrairement à `atan` seul) donne un angle correct sur les 360°, en tenant compte du signe de x et y.

## Rotation d'un élément (pinch/rotate)

Faire tourner un point autour d'un centre :

<Math display>{`x' = x\\cos\\theta - y\\sin\\theta`}</Math>
<Math display>{`y' = x\\sin\\theta + y\\cos\\theta`}</Math>

<CodeEditor
  initialCode={`import math

def swipe_direction(x1, y1, x2, y2):
    dx = x2 - x1
    dy = y2 - y1
    angle = math.degrees(math.atan2(dy, dx))

    if -45 <= angle <= 45:
        return "droite"
    elif 45 < angle <= 135:
        return "bas"
    elif angle > 135 or angle < -135:
        return "gauche"
    else:
        return "haut"

# Exemple : swipe vers le haut
print(swipe_direction(100, 300, 105, 50))

# Exemple : swipe vers la droite
print(swipe_direction(50, 200, 300, 205))`}

<Callout type="tip" title="Astuce">
Utilise toujours `atan2(dy, dx)` plutôt que `atan(dy/dx)` — atan2 gère correctement les 4 quadrants et évite les divisions par zéro quand dx = 0.
</Callout>
